# 🔍 Детектор Фейковых Новостей

Проверка новостей на достоверность с помощью ML и фактчекинга.

## Особенности

- ✅ Стилевая модель (SVM, 95.48% accuracy)
- ✅ Фактчекинг (Wikipedia + DuckDuckGo + RSS)
- ✅ 12 тем (еда, учёба, ИИ, наука, IT, игры, кино, музыка, спорт, путешествия, факты)
- ✅ 20+ RSS лент
- ✅ История проверок
- ✅ Статистика

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Технологии

- Python
- Streamlit
- scikit-learn
- DuckDuckGo Search
- Wikipedia API
