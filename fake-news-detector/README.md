# Fake News Detector

Fake News Detector — веб-приложение для проверки достоверности новостных утверждений на русском языке.

Система ищет источники в интернете, сравнивает утверждение с найденной информацией, проверяет смысл через NLI-модель и выдаёт один из вердиктов:

- **ПРАВДА** — утверждение подтверждено надёжными источниками;
- **ФЕЙК** — найдено противоречие с источниками;
- **НЕИЗВЕСТНО** — информации недостаточно для надёжного вывода.

## Возможности

- Проверка коротких утверждений и новостных текстов.
- Разбиение сложного текста на отдельные смысловые утверждения.
- Поиск источников через DuckDuckGo, Wikipedia API и RSS-ленты.
- Открытие веб-страниц и извлечение основного текста статьи.
- Поиск подтверждений и опровержений.
- Проверка числовых данных и направления: рост или снижение.
- Проверка смысла через NLI-модель.
- Оценка надёжности источников.
- Стилевая ML-модель для дополнительного анализа текста.
- Кэширование результатов поиска.
- Тестовая страница для оценки точности фактчекера и ML-модели.

## Как работает фактчекер

1. Пользователь вводит новость или утверждение.
2. Текст очищается от лишних символов.
3. Текст разбивается на короткие смысловые утверждения.
4. Для каждого утверждения формируются поисковые запросы.
5. Система ищет источники в DuckDuckGo, Wikipedia и RSS-лентах.
6. Открывает наиболее подходящие страницы и извлекает текст.
7. Ищет предложения, похожие на проверяемое утверждение.
8. Проверяет числа и направление: рост или снижение.
9. Проверяет смысл через NLI-модель.
10. Оценивает надёжность источника.
11. Объединяет результаты и выдаёт итоговый вердикт.

### Пример

Ввод:

```text
Вода кипит при 100 градусах, а Земля плоская.
```

Система разбивает текст на части:

```text
1. Вода кипит при 100 градусах
2. Земля плоская
```

Первая часть подтверждается источниками, вторая противоречит им.

Итоговый вердикт:

```text
ФЕЙК
```

Потому что в утверждении есть недостоверная часть.

## Запуск локально

1. Клонируй репозиторий:

```bash
git clone [https://github.com/michaelkochetkov5-gif/fake-news-detector.git](https://github.com/michaelkochetkov5-gif/fake-news-detector.git)
cd fake-news-detector
```

2. Установи зависимости:

```bash
pip install -r requirements.txt
```

3. Запусти приложение:

```bash
streamlit run site.py
```

4. Открой в браузере:

```text
http://localhost:8501
```

## Важное ограничение

Фактчекер не может гарантированно определить правду, если в интернете нет надёжных источников или если источники противоречат друг другу.

В таких случаях система честно возвращает:

```text
НЕИЗВЕСТНО
```

Это лучше, чем случайно назвать правду фейком или подтвердить ложное утверждение.
