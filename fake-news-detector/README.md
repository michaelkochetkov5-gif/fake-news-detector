# 🔍 Fake News Detector

**Система проверки достоверности новостей и утверждений на русском языке.**

Принимает текст, находит релевантные источники в интернете, сопоставляет их с утверждением — сначала по словам и числам, затем по смыслу — и выносит вердикт, указывая, на чём именно он основан.

## 🎯 Вердикты

| Вердикт | Что означает | Уверенность |
|---|---|---|
| ✅ **ПРАВДИВАЯ НОВОСТЬ** | Утверждение подтверждено источниками | по расчёту |
| ❌ **ФЕЙКОВАЯ НОВОСТЬ** | Найдено противоречие с источниками | по расчёту |
| ⚠️ **НЕДОСТАТОЧНО ДАННЫХ** | Информации мало для вывода | по расчёту |
| ⚠️ **БОЛЬШИЕ СОМНЕНИЯ** | Ни одна ступень не смогла решить | **фиксировано 20%** |

`БОЛЬШИЕ СОМНЕНИЯ` — не отказ и не замаскированный фейк. Это честная констатация: источников недостаточно, и система не берётся утверждать ни в одну сторону. Возникает в двух случаях: FactChecker не уверен и FLUD не вызывался, либо обе ступени не смогли дать вердикт.

Каждый ответ несёт поле `decision_source` — какая именно ступень вынесла решение.

## 🧩 Принцип работы

Проверка двухступенчатая. Вторая ступень включается только тогда, когда первая не уверена — так экономится инференс NLI, а решение остаётся объяснимым.

```
                    Текст пользователя
                            │
                            ▼
              ┌─────────────────────────────┐
              │   СТУПЕНЬ 1 — FactChecker   │
              │  DuckDuckGo · Wikipedia ·   │
              │        RSS-ленты            │
              └─────────────┬───────────────┘
                            │
                   источники + цитаты
                            │
                  ┌─────────┴─────────┐
                  │   уверен? ≥ 0.50  │
                  └─────────┬─────────┘
                      ДА    │    НЕТ
                   ┌────────┘    └────────┐
                   ▼                      ▼
              ┌─────────┐      ┌───────────────────┐
              │ вердикт │      │ СТУПЕНЬ 2 — FLUD  │
              │   FC    │      │  NLI + numeric    │
              └─────────┘      └─────────┬─────────┘
                                         ▼
                              ┌─────────────────────┐
                              │  combine() — итог   │
                              └─────────────────────┘
```

### Ступень 1 — FactChecker

Проверка по источникам, без нейросетей:

- **Поиск** — DuckDuckGo (несколько стратегий запросов), Wikipedia API (статьи и полный текст), RSS-ленты пяти изданий
- **Разбор текста** — деление сложного текста на отдельные утверждения, оценка важности каждого
- **Извлечение сущностей** — ключевые термины, страны, годы, числа с единицами измерения
- **Сверка** — числовые отношения (рост/снижение), хронологические конфликты, конфликты стран, тематическое соответствие источника
- **Отбор доказательств** — поиск наиболее релевантных предложений в тексте источника, оценка поддержки
- **Защита от сенсаций** — если вердикт ПРАВДА, но в тексте есть сенсационные маркеры, результат понижается до НЕИЗВЕСТНО (уверенность 0.45).

### Ступень 2 — FLUD

**Fact Lie Utility Detector.** Семантическая проверка — смотрит на смысл, а не на совпадение слов.

| Компонент | Роль |
|---|---|
| NLI cross-encoder | Определяет отношение цитаты к утверждению: противоречие / следование / нейтрально |
| Numeric checker | Сверяет числа между утверждением и цитатой, может скорректировать вероятность |

**Как FLUD приходит к решению:**

1. **Извлечение premise** — из результатов FactChecker берутся цитаты источников в кавычках (до трёх на источник). Это фрагменты реальных текстов, а не пересказ.
2. **Оценка пар** — каждая цитата сравнивается с утверждением через NLI. Модель выдаёт три вероятности: противоречие, следование, нейтрально.
3. **Выбор максимумов** — среди всех цитат берётся наибольшая вероятность противоречия и наибольшая вероятность следования.
4. **Решение** — если противоречие ≥ следования, вердикт ФЕЙК, иначе ПРАВДА. Уверенность равна большему из двух значений.
5. **Поправка на числа** — numeric checker сравнивает числа в утверждении и в лучшей цитате. При расхождении вероятность противоречия может быть скорректирована.
6. **Порог** — если итоговая уверенность ниже `MIN_CONFIDENCE` (0.50), вердикт НЕИЗВЕСТНО.

### Сведение результатов

| Ситуация | `decision_source` |
|---|---|
| FactChecker уверен | `factchecker` |
| Обе ступени согласны | `factchecker+flud` |
| Вердикты противоположны | `uncertain` |
| FactChecker не уверен — решает FLUD | `flud` |
| Обе не уверены | `uncertain` → БОЛЬШИЕ СОМНЕНИЯ |

Служебные значения FLUD: `nli` — решение принято, `nli_uncertain` — ниже порога, `nli_no_premise` — источники не содержат цитат, `nli_unavailable` — модель не загрузилась, `nli_error` — сбой инференса.

### Что внутри numeric checker

Извлекает числа с единицами и процентами, сопоставляет утверждение с источником и присваивает каждому числу статус:

| Статус | Значение |
|---|---|
| `exact` | Точное совпадение |
| `rounded` | Округление |
| `derived` | Производное значение |
| `percent_equiv` | Эквивалент в процентах |
| `mismatch` | Расхождение |
| `unit_mismatch` | Разные единицы измерения |

## ⚠️ Ограничения

Честно о том, что важно знать до использования:

- **Не оракул.** Система сопоставляет текст с источниками, а не устанавливает истину. Нет источника — нет подтверждения.
- **Уверенность не калибрована.** Softmax NLI-модели систематически переуверен: 100% в интерфейсе не означает нулевую вероятность ошибки.
- **Решает одна цитата.** Итог определяется самым «противоречащим» фрагментом; подтверждающие цитаты на вердикт не влияют. Одна нерелевантная статья может перевесить несколько релевантных.
- **Свежие новости проверяются плохо.** Wikipedia не успевает за событиями дня, RSS покрывает пять изданий. Событие, о котором ещё не написали, получит БОЛЬШИЕ СОМНЕНИЯ — это корректное поведение, а не сбой.
- **Числа прописью не распознаются.** «два», «три», «полтора» — вне возможностей numeric checker.
- **`flud_checker.py` не подключён.** Модуль с LoRA-обёрткой лежит в проекте, но интерфейс использует NLI-проверку из `nli_checker.py`. LoRA-веса в пайплайне не участвуют.
- **Стилевая модель не в пайплайне.** Файлы `.pkl` используются только страницей диагностики.
